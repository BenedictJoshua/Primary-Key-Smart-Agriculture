# Frontend

This folder contains the React + Vite frontend application for the Smart Agriculture Intelligence Portal.

## What is started here
- A responsive landing/dashboard-style homepage for the portal.
- A UI direction focused on farmers, crop guidance, and market insight.
- A visual foundation the team can expand into pages, components, and data views.

## Suggested next pages
- Dashboard
- Crop recommendations
- Crop knowledge base
- Market insights
- Alerts and notifications
